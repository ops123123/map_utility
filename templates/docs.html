Welcome to the Coordinate Converter & Route Planner

This application is a comprehensive web-based tool for coordinate conversion, geocoding, and route planning with traffic visualization. It combines multiple mapping features into one powerful interface.

🎯 Key Features:
  • Bidirectional coordinate conversion (X,Y ↔ Lat/Lon)
  • Interactive map with marker placement
  • Address geocoding and reverse geocoding
  • Route calculation with traffic simulation
  • Multiple route alternatives
  • Manual location picking on map
  • Traffic congestion visualization

Technology Stack

Component Technology
Backend Flask (Python 3.x)
Frontend HTML5, CSS3, JavaScript
Mapping Leaflet.js with OpenStreetMap tiles
Geocoding Nominatim API
Routing OSRM (Open Source Routing Machine)
Projections pyproj (EPSG:4326 ↔ EPSG:3857)
✨ What's Special:

This app uses the Web Mercator projection (EPSG:3857) for coordinate conversion - the same system used by Google Maps, Bing Maps, and most web mapping services. This makes it perfect for converting between display coordinates and geographic coordinates.

Coordinate Conversion

The app provides two-way conversion between Web Mercator (X,Y) coordinates and WGS84 (Lat/Lon) geographic coordinates.

X,Y to Lat/Lon Converter

Purpose: Convert Web Mercator coordinates (in meters) to latitude/longitude degrees.
Example:
Input: X = -8238310.724, Y = 4970241.327
Output: Lat = 40.74881700°, Lon = -73.98542800°
(This is Times Square, New York!)

Features:

  • Enter X and Y values in meters
  • Results shown with 8 decimal precision for lat/lon
  • Adds a blue marker to the map
  • Automatically zooms to show the location
  • Clear button to reset inputs

Lat/Lon to X,Y Converter

Purpose: Convert latitude/longitude degrees to Web Mercator coordinates (in meters).
Example:
Input: Lat = 40.748817, Lon = -73.985428
Output: X = -8238310.724000 m, Y = 4970241.327000 m

Features:

  • Enter latitude and longitude in degrees
  • Results shown with 6 decimal precision for X/Y
  • Adds a green marker to the map
  • Automatically zooms to show the location
  • Clear button to reset inputs

About Coordinate Systems

System Code Description
WGS84 EPSG:4326 Standard GPS coordinates (latitude/longitude in degrees)
Web Mercator EPSG:3857 Projected coordinates used by web maps (X/Y in meters)
⚠️ Note: Web Mercator projection distorts areas near the poles. It's accurate for most populated areas but should not be used for high-latitude regions (above 85°N or below 85°S).

Address Search

Search for any address, place name, or point of interest worldwide using the OpenStreetMap Nominatim geocoding service.

How to Use

  1. Enter an address or place name in the search field
  2. Click the Search button
  3. Review up to 5 results with detailed information
  4. Click "Show on Map" to view the location

Search Examples

By Landmark: "Eiffel Tower, Paris"
By Address: "1600 Pennsylvania Avenue, Washington DC"
By Coordinates: "40.7484, -73.9857"
By Place: "Central Park, New York"
By Region: "Tokyo, Japan"

Result Information

Each search result includes:

  • Display Name: Full formatted address
  • Latitude & Longitude: WGS84 coordinates (8 decimal places)
  • X & Y: Web Mercator coordinates (6 decimal places)
  • Show on Map button: Instantly view location with a red marker
💡 Pro Tip: The geocoder supports multiple languages and formats. Try searching in different languages or using local address formats for better results!

Rate Limiting

⚠️ Important: The Nominatim service has usage limits. There is a 1-second delay between requests to comply with their fair use policy. Please be patient when searching!

Distance Calculator with Traffic

Calculate driving routes between two locations with traffic simulation and multiple alternative routes.

Basic Usage

  1. Enter source and destination addresses
  2. Select traffic time period (optional)
  3. Enable/disable traffic color visualization
  4. Click Calculate Routes
  5. View main route + up to 2 alternatives

Manual Location Picking

Instead of typing addresses, you can pick exact locations on the map:

  1. Click the "📍 Pick on Map" button for source or destination
  2. Button turns orange and says "Click on map..."
  3. Click anywhere on the map to set the location
  4. Address is automatically filled via reverse geocoding
  5. A marker appears at the selected location
✨ Tip: Manual picking is perfect for precise locations like building entrances, parking lots, or specific intersections!

Swap Function

The 🔄 swap button instantly reverses your source and destination, including:

  • Text input fields
  • Manual coordinates (if set)
  • Map markers

Route Information

For each route, you'll see:

  • Distance: In kilometers and miles
  • Base Time: Duration without traffic
  • With Traffic: Adjusted duration based on selected time
  • Traffic Level: Clear, Light, Heavy, or Severe

Traffic Visualization

When "Show Traffic Congestion Colors" is checked:
  • Blue: Clear - normal traffic
  • Orange: Light - slight delays
  • Red-Orange: Heavy - significant delays
  • Red (dashed): Severe - major congestion

Alternative Routes

The app shows up to 3 routes:

  • Main Route: Fastest or most direct (thicker line)
  • Alternative 1 & 2: Other viable options (thinner lines)

Click any route line to see a popup with details.

Tips & Tricks

🎯 Best Practices

For Accurate Conversions:
  • Use full precision values when available
  • Web Mercator works best between 85°N and 85°S
  • Double-check coordinate order (X/Lon comes before Y/Lat in many systems)
For Better Geocoding:
  • Include city and country for ambiguous place names
  • Use official address formats when possible
  • Try different variations if first search fails
  • Be patient - 1 second delay between requests is normal
For Route Planning:
  • Use manual picking for precise start/end points
  • Compare alternative routes before deciding
  • Consider traffic times for realistic planning
  • Remember: traffic multipliers are simulated, not real-time

⚡ Productivity Shortcuts

  1. Quick View: After any conversion/search, use "Fit to Markers" to see everything
  2. Clear Start: Use "Clear Markers" before starting a new task
  3. Route Comparison: Leave traffic colors on to visually compare congestion
  4. Precise Placement: Zoom in close before using manual picker
  5. Reverse Trip: Use swap button to quickly plan return journey

Frequently Asked Questions

General Questions

Q: Is this app free to use?
A: Yes! It uses free, open-source APIs and services.
Q: Do I need to create an account?
A: No, the app works without any registration or login.
Q: What browsers are supported?
A: All modern browsers (Chrome, Firefox, Safari, Edge). Internet Explorer is not supported.

Coordinate Conversion

Q: What's the difference between EPSG:4326 and EPSG:3857?
A: EPSG:4326 (WGS84) uses latitude/longitude in degrees. EPSG:3857 (Web Mercator) uses projected X/Y coordinates in meters, commonly used by web maps.
Q: Why do my converted coordinates look different from other tools?
A: Different tools may use different precisions or rounding. Our app uses high precision (8 decimals for lat/lon, 6 for X/Y) for accuracy.
Q: Can I convert coordinates at the poles?
A: Web Mercator doesn't work beyond 85.05° latitude. For polar regions, use a different projection system.

Address Search & Geocoding

Q: Why is there a delay after searching?
A: The Nominatim API requires a 1-second delay between requests to prevent abuse. This ensures the service remains free for everyone.
Q: Can I search for coordinates directly?
A: Yes! Enter coordinates in "lat, lon" format (e.g., "40.7484, -73.9857").
Q: Why do I get multiple results?
A: Many place names exist in multiple locations. For example, "Springfield" exists in over 30 U.S. states. Review all results to find the right one.

Route Planning

Q: Is the traffic data real-time?
A: No, traffic adjustments are simulated based on typical patterns. For real-time traffic, use dedicated navigation apps.
Q: Why are there only 3 routes maximum?
A: The OSRM API returns up to 3 feasible alternatives to keep the display clean and focus on the best options.
Q: Can I plan routes for walking or cycling?
A: Currently, only driving routes are supported. The OSRM service focuses on car routing.
Q: What if no route is found?
A: This happens when locations aren't connected by roads (e.g., different islands, blocked areas). Try nearby points that are road-accessible.

Technical Questions

Q: What APIs does this app use?
A:
- OpenStreetMap for map tiles
- Nominatim for geocoding
- OSRM for routing
- pyproj for coordinate transformation
Q: Can I use this app offline?
A: No, it requires internet connection to access map tiles and API services.
Q: Is my data stored anywhere?
A: No, all processing happens in your session. No searches or conversions are saved.
